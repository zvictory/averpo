## Майдон даражаси (?) рўйхати (биринчи тўплам)

**Ҳужжат формалари**:

- Бирлик ва factor (unit group);

- Reconciliation кўчирма қолдиғи; Opening balance (OBE);

- Estimate амал муддати; Тўлов шарти (payment term).

**Ҳисоботлар**: aging bucket'лар (жорий/1-30/31-60/61-90/90+),
statement running balance, «Барча суммалар <home> да» маъноси.
