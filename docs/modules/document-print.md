# Ҳужжатни чоп этиш / PDF - SPEC (тасдиқ КУТМОҚДА, 2026-07-11)

Манба: review/backlog/2026-07-08-Arbitr-040-hujjat-chop-etish-pdf-email.md
(NAVBAT 29-банд, фойдаланувчи 1.0 кўламига киритган).

## Мақсад

Мижозга бериладиган ҳужжат формати: invoice/estimate/CM/SR кўриш
экранидан бир босишда A4 чоп кўриниши - компания реквизити + логотип
+ ҳужжат таркиби + ҚҚС ажратмаси + жами. PDF - браузернинг ўз
print-to-PDF'и орқали (MVP). Кичик бизнеснинг кундалик эҳтиёжи:
invoice харидорга берилади/жўнатилади.

## QBO билан солиштирув

QBO ҳар мижоз ҳужжатида Print ва Send тугмаси беради (Print preview -
компания логотипи, реквизит, жадвал, жами). Finance.xsd'да
EmailStatus/DeliveryInfo майдонлари бор - лекин EMAIL юбориш бизда
2-БОСҚИЧ (SMTP кўп бизнесда йўқ - backlog карта қарори «Print/PDF
аввал»). Server-side PDF кутубхонаси ҲАМ 2-босқич (янги dependency -
браузер print-to-PDF MVP эҳтиёжни тўлиқ ёпади). Бу иккиси MVP'дан
онгли чиқарилган - фойдаланувчи тасдиғи шу кўламга олинади.

## Кўлам (MVP)

1. **Print қатлами**: Statement (25-банд)да ётқизилган shared print
   нақши (@media print, сайдбар/меню яширин, A4) тўртта ҳужжатга
   кенгаяди: **invoiceView, estimateView, creditMemoView,
   salesReceiptView** (+ statement аллақачон бор). Bill/PO -
   2-босқич (таъминотчига чоп этиш камдан-кам).
2. **Чоп сарлавҳаси (shared partial)**: компания номи + логотип +
   реквизитлар + ҳужжат рақами/санаси + мижоз блоки. Барча ҳужжатда
   бир хил қолип - shared/printHead.jte (янги).
3. **Ҳужжат таркиби**: сатрлар жадвали (товар/тавсиф/миқдор+бирлик/
   нарх/сумма), ҚҚС ажратмаси (Оралиқ жами / ҚҚС / Жами - мавжуд
   breakdown қолипи), ҳужжат валютасида; чет валютада home жами ҳам
   (088 қолипи). Тўловлар/қолдиқ блоки invoice'да (тўланган/қолдиқ).
4. **CompanySettings реквизитлари** - **ЭНДИ docs/modules/company-info.md
   ЭГАЛИК ҚИЛАДИ** (changeset 054: манзил/телефон/СТИР/банк/директор/
   лого + «Компания маълумотлари» саҳифаси, Arbitr-112, 2026-07-12).
   Бу карта (29) уларни фақат ЎҚИЙДИ (чоп сарлавҳасида ном+лого+
   реквизит). Такрор changeset/майдон ЁЗМА - company-info тайёр
   бўлгач шу майдонларни render қил (лого йўқ бўлса блок жим тушади).
5. **Тугма**: ҳар қамровдаги view'да «Чоп этиш» (window.print -
   Statement прецеденти). PDF = браузер print диалогидаги «Save as
   PDF» - алоҳида тугма ЙЎҚ (MVP).
6. Чоп тили - жорий UI тили (мижоз тилини танлаш 2-босқич).

## Дизайн қарорлари

- Ташқи PDF кутубхонаси ЙЎҚ (стек қоидаси; браузер кифоя).
- Печат кўриниши АЛОҲИДА саҳифа эмас - мавжуд view'нинг @media print
  ҳолати (Statement айнан шундай) - маршрут/controller ўзгармайди.
  Экран-фақат блоклар (тугмалар, GL линк, иловалар, сторно формаси,
  (?) тугмалари) print'да яширин (helpDialog print қоидаси тайёр).
- Логотип файли: PNG/JPG, чекланган ҳажм (мавжуд attachments 20MB
  чегараси остида, тавсия ≤1MB); сақлаш attachments директория
  қолипида (диск ном - server UUID).
- Яхлитлаш/формат: Fmt қоидалари айнан (пул 2 хона, NBSP, миқдор
  бирлиги билан).
- BR кодлари КУТИЛМАЙДИ (кўрсатиш иши); реквизит майдонлари оддий
  узунлик чеклови билан.

## Тестлар (мажбурий рўйхат)

1. Print кўриниш render (web тест): printHead блоки (компания ном +
   реквизит) + ҚҚС ажратмаси + жами ҳужжат қийматларига тенг.
2. Логотип йўқ ҳолат - блок жим тушади (null-safe).
3. Реквизитлар settings формасида сақланади/қайтади (round-trip).
4. Мавжуд ScreenSmoke яшил.
5. ЖОНЛИ smoke: invoice печат кўриниши (browser print preview) -
   A4'да сайдбарсиз, реквизит+лого кўринади (скриншот/DOM далил);
   375px экран оқимига таъсир йўқ.
