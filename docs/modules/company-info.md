# Компания маълумотлари (company info) - SPEC

Ҳолат: **ТАСДИҚЛАНГАН** (фойдаланувчи: майдонлар тўғри,
директор + банк ҳам). UX кўригидан кейин карта.

Манба: фойдаланувчи талаби: user profile саҳифаси билан
бирга company info саҳифаси. Реквизит майдонлари аллақачон
docs/modules/document-print.md (29) да changeset 054 сифатида
режаланган эди (чоп сарлавҳаси учун) - шу майдонлар СОФ МАНБАСИ энди
шу спец; document-print уларни ЎҚИЙДИ (такрор эмас).

## QBO билан солиштирув

QBO «Account and Settings → Company»: company name, legal name, EIN/
tax, address, email, phone, website, logo. Бизники + Ўзбекистон
реквизитлари (СТИР/ИНН, банк, директор - ҳужжат/чоп учун).

## Кўлам

Settings остида алоҳида **«Компания маълумотлари»** саҳифаси
(SUPER_ADMIN) - компаниянинг ўзлигини бошқаради; чоп сарлавҳаси,
ҳужжатлар, келгусида ҳисоботлар шундан ўқийди.

Майдонлар (CompanySettings singleton'ига, changeset 054 - ҳаммаси
ихтиёрий/nullable, `name` мавжуд):
- `name` (қисқа/кўринадиган ном) - МАВЖУД;
- `legal_name` (тўлиқ юридик ном);
- `address` (матн, кўп қатор);
- `phone`, `email`, `website`;
- `tax_id` (СТИР/ИНН - матн);
- **банк**: `bank_name`, `bank_account`, `bank_mfo`;
- **директор**: `director_name`, `director_position`;
- **компания логоси**: `logo_attachment_id` (FK → attachment) -
  **ҲУЖЖАТ чоп сарлавҳаси ва ҳисоботларда** (document-print 29). (?)
  helper шуни тушунтиради (help.field.companyLogo ×3);
- **бренд логоси**: `brand_logo_attachment_id` (FK → attachment) -
  **ИЛОВА ТОПБАРИДА** (login'дан кейин, илованинг стандарт бренд
  ёзуви ўрнига компаниянинг ЎЗ бренди; созланмаса fallback). Company logo'дан
  ФАРҚли мақсад (жонли топилма; ТАСДИҚЛАНДИ: компаниянинг
  бренди, white-label - топбардаги стандарт бренд ёзуви ўрнига).
- ҳар икки лого + аватар: png/jpeg/webp, 2MB, SVG ТАҚИҚ (094 нақши) +
  **ЎЛЧОВ текшируви** (қуйида).

## Дизайн қарорлари

- Барчаси **CompanySettings**'да (singleton - битта компания). Янги
  entity ЙЎҚ.
- Лого: мавжуд **Attachment** инфраси (101 аватар + document-print
  лого билан бир хил): GET /company/logo inline+nosniff (094 қоидаси),
  ўчириш; DOCUMENT_TABLES'га (агар APP_USER/COMPANY тури керак бўлса)
  SABOQLAR тип-харита свипи - ёки company singleton'га content_type
  билан бирикади (имплементацияда ҳал, BR-ATT-003 тузоғи текширилади).
- **РАСМ ЎЛЧОВ текшируви (жонли топилма)**: файл ҳажми
  (2MB)/тури'дан ташқари расм ЎЛЧОВИ (кенглик×баландлик, ImageIO.read)
  текширилади - жуда катта/кичик рад (мин/макс диапазон, BR-COM/USR).
  **Бренд логоси ҚАТЪИЙроқ** (топбар - сайт бузилмасин): (а) upload
  ўлчов диапазони + (б) топбарда CSS max-height (қандай юкланса ҳам
  сиғади). Битта умумий валидатор (company logo + бренд + аватар 101 -
  такрор эмас, диапазонлар параметр).
- Company name company info саҳифасида ҲАМ кўринади/таҳрирланади
  (айнан CompanySettings.name; Созлама билан бир манба).
- Реквизитлар GL/posting'га таъсир қилмайди (соф кўрсатиш маълумоти);
  BR кодлари деярли керак эмас (email формат BR-CON нақшидан, agar
  керак бўлса).
- Валидация: email формати (ихтиёрий, тўлдирилса текширилади); лого
  тури/ҳажми (расм BR).
