# Excel'дан бошланғич import - SPEC (ТАСДИҚЛАНГАН)

## Мақсад

Янги компания тизимга кирганда БИТТА Excel (.xlsx) файлни юклаб,
энг минимал маълумот билан ишлаб кетади: контактлар ва товарлар.
Setup оқими (DEC-056) билан бирлашади - «Хуш келибсиз» banner'ида
ва /settings'да «Excel'дан юклаш» ҳаволаси.

Эталон: QBO import (Settings → Import data: Customers/Suppliers/
Products and services - айнан шу учлик, CSV/Excel). Бизда QBO'дан
фарқли БИТТА кўп варақли файл - фойдаланувчига битта қадам.

## Кўлам (1-босқич - ЭНГ МИНИМАЛ)

- Битта .xlsx файл, БЕШ варақ (номи бўйича танилади, рўйхатдан
  ташқари варақлар индамай ўтказилади - шаблондаги «Йўриқнома» шундай):
  - **«Контактлар»**, **«Ходимлар»**, **«Товарлар»**, **«Омборлар»**,
  **«Счётлар»** (фойдаланувчи кенгайтмаси: «омборлар,
    счётлар, ходимлар ҳам - 2-5 тадан»).
- «Счётлар» ФАҚАТ пул счётлари (банк/касса) - янги компанияга айнан
  шулар керак; тўлиқ счётлар режаси import'и ҚИЛИНМАЙДИ (seed режа
  аллақачон бор, IFRS тузилмаси бузилмасин) - зарурати чиқса 2-босқич.
- Бухгалтерия қолдиқлари (банк/омбор/AR/AP opening balance) - 2-босқич:
  улар GL проводка талаб қилади (PostingService, темир қоидалар),
  минимал оқимга кирмайди. Import яратган счёт/омборлар БЎШ очилади.
- Файл чегараси: 5MB, ҳар варақда 2000 сатргача (BR-IMP-004).

## Варақ форматлари (1-қатор - сарлавҳа, айнан шу тартиб)

«Контактлар»:

| устун | мажбурий | изоҳ |
|---|---|---|
| Номи | ҲА | displayName; файл ичида ва базада ноёб текширилади |
| Тури | ҲА | МИЖОЗ / ТАЪМИНОТЧИ (кирилл, катта-кичик фарқсиз; ходимлар алоҳида варақда) |
| Телефон | йўқ | phone |
| Email | йўқ | email |
| ИНН | йўқ | taxId |
| Изоҳ | йўқ | notes |

Қолган майдонлар (валюта, тўлов шарти, кредит лимити) import
қилинмайди - кейин карточкада тўлдирилади (минималлик).

«Ходимлар» (ContactType.EMPLOYEE яратилади):

| устун | мажбурий | изоҳ |
|---|---|---|
| Номи | ҲА | displayName; ноёблик контактлар билан умумий |
| Телефон | йўқ | phone |
| Ойлик (гросс) | йўқ | monthlySalary (FormParsers); payroll prefill ишлатади |
| Изоҳ | йўқ | notes |

«Омборлар»:

| устун | мажбурий | изоҳ |
|---|---|---|
| Номи | ҲА | WarehouseService.create орқали |
| Код | йўқ | code (ноёб) |

«Счётлар» (фақат пул счётлари):

| устун | мажбурий | изоҳ |
|---|---|---|
| Номи | ҲА | AccountService.create орқали (BR-COA ноёблик ўзи текширади) |
| Тури | ҲА | БАНК → CHECKING / КАССА → CASH_ON_HAND |
| Валюта | йўқ | ISO код (UZS, USD...); бўш = home currency; каталогда бўлиши шарт |
| Код | йўқ | счёт коди (ноёб) |

«Товарлар»:

| устун | мажбурий | изоҳ |
|---|---|---|
| Номи | ҲА | name; ноёблик текширилади |
| Тури | ҲА | ТОВАР / ХИЗМАТ (ITEM/SERVICE) |
| Бирлик | ҲА (ТОВАРда) | Unit каталогидан НОМИ бўйича; топилмаса ХАТО (каталогга ишора) - жимгина яратилмайди |
| SKU | йўқ | sku |
| Сотув нархи | йўқ | salesPrice (FormParsers форматлари) |
| Харид нархи | йўқ | purchaseCost |
| ҚҚС ставкаси | йўқ | TaxRate каталогидан НОМИ бўйича (sales+purchase иккисига) |

Счёт боғламалари (income/expense/inventory account) import'да
СЎРАЛМАЙДИ - ItemService мавжуд default'лари ишлайди (invoice/bill
оқимидаги нақш).

## Дизайн қарорлари

- **Кутубхона**: Apache POI (poi-ooxml) - янги dependency, фақат
  xlsx ўқиш (SXSSF керак эмас, 2000 сатр чегараси бор).
- **Транзакция: ҳаммаси-ёки-ҳеч-нарса.** Битта сатрда ҳам хато бўлса
  ҲЕЧ НАРСА import қилинмайди, хатолар рўйхати сатр рақами билан
  экранга чиқади («Контактлар 14-сатр: Тури нотўғри...»). Фойдаланувчи
  файлни тузатиб қайта юклайди - ярим import'дан кўра шу аниқроқ.
- **Дубликат сиёсати**: файл ичида такрор ном = ХАТО; базада мавжуд
  ном = ХАТО эмас, сатр ЎТКАЗИЛАДИ ва ҳисоботда «мавжуд - ўтказилди»
  деб кўрсатилади (қайта юклаш idempotent бўлади).
- **Модул**: shared (импорт иккала каталогга тегади) -
  `shared.service.ExcelImportService` + `shared.web.ImportController`;
  ContactService/ItemService PUBLIC api орқали ёзади (қоида 6 -
  repository'ларга тегилмайди).
- **Роль**: SETTINGS соҳаси - амалда SUPER_ADMIN (settings нақши).
- **Шаблон**: `GET /settings/import/template` - тайёр статик .xlsx
  (src/main/resources/static/import-template.xlsx, АРБИТР ЯСАГАН: иккала варақ сарлавҳалари + 2 тадан намуна сатр +
  «Йўриқнома» варағи - import уни индамай ўтказади). Фойдаланувчи
  шуни тўлдиради.
- GL'га ҲЕЧ НАРСА ёзилмайди - PostingService чақирилмайди (1-босқич).
- Changeset КЕРАК ЭМАС (schema ўзгармайди).

## Валидация (BR-IMP - аввал каталогга, қоида 13)

- BR-IMP-001: файл .xlsx ва 5MB'дан кичик бўлиши шарт.
- BR-IMP-002: мажбурий устун бўш / Тури нотанилган қиймат.
- BR-IMP-003: файл ичида такрор ном (варақ+сатр кўрсатилади).
- BR-IMP-004: варақда 2000 сатрдан кўп.
- BR-IMP-005: Бирлик/ҚҚС ставкаси/Валюта каталогда топилмади.
- Хатолар БИТТА жавобда тўлиқ рўйхат бўлиб қайтади (биринчисида
  тўхтамайди) - фойдаланувчи бир юришда ҳаммасини тузатади.

## Service API

- `ExcelImportService.parse(file)` → `ImportPreview` (сатрлар +
  хатолар рўйхати) - ўқиш соф, ёзмайди.
- `ExcelImportService.apply(preview)` → `ImportResult` (нечта
  контакт/товар яратилди, нечта ўтказилди) - @Transactional.
- Controller: юклаш → хато бўлса рўйхат экранда; тоза бўлса дарҳол
  apply + натижа flash хабари (алоҳида preview-тасдиқ қадами ЙЎҚ -
  минималлик; 2-босқичда кўриб чиқилади).

## Тестлар (мажбурий)

1. Тоза файл: контакт+ходим+товар+омбор+счёт яратилади, сони тўғри
   (счёт тури/валютаси, ходим ойлиги assert).
2. Хатоли сатр: ҲЕЧ НАРСА ёзилмайди, хато рўйхати сатр рақами билан.
3. Дубликатлар: файл ичи = хато; базада мавжуд = ўтказилди.
4. БЎШ/нотанилган варақли файл: тушунарли хато.
5. Бирлик топилмади (BR-IMP-005).
6. ScreenSmokeTest: /settings/import GET.
7. Шаблон файли: юклаб олинганда парс бўлади (round-trip).

## Экранлар

- `/settings/import` (SETTINGS соҳаси): шаблонни юклаб олиш ҳаваласи + файл
  танлаш формаси (attachments upload нақши, CSRF) + натижа/хатолар
  жадвали. Мобил 375px, .table-wrap.
- Setup banner'ида (056) ва /settings саҳифасида ҳавола.

## 2-босқич (ҳозир ЭМАС - алоҳида келишилади)

- «Қолдиқлар» варағи: банк/касса, омбор (item+qty+таннарх),
  AR/AP контакт кесимида - opening balance JE + StockMovement
  (PostingService орқали, AVCO/FIFO seed).
- Preview-тасдиқ қадами; Омборлар/Счётлар режаси варақлари; CSV.
