# Контакт карточкаси (мижоз/таъминотчи саҳифаси) - SPEC (ТАСДИҚЛАНГАН)

## Мақсад

Мижоз/таъминотчи рўйхатидан контакт босилганда ТАҲРИР ФОРМАСИ эмас,
КОНТАКТ САҲИФАСИ очилади: муҳим кўрсаткичлар + шу контактнинг тўлиқ
кўчирмаси (statement) ўша ойнанинг ўзида. Фойдаланувчи талаби
(намуна скриншот билан); DEC-002 backlog картасининг
триггери отилди. Эталон: QBO Customer/Vendor саҳифаси (транзакциялар
рўйхати + баланс + карточка маълумоти).

## Кўлам (1-босқич - MVP)

Янги саҳифалар: `/customers/{id}` ва `/vendors/{id}` (кўриш).
Таркиби юқоридан пастга:

1. **Сарлавҳа**: контакт номи + тури + «Таҳрир» тугмаси (эски форма
   /customers/{id}/edit га кўчади) + «Печат кўчирма» линки (мавжуд
   statement print).
2. **Стат-карталар (4 та, метрик карта услуби)**:
   - «Жорий қолдиқ» - AR/AP нетто (StatementService closing бугунги
     сана билан); аванс (салбий AR / дебет AP) бўлса яшил «Аванс»
     белгиси билан кўрсатилади;
   - «Муддати ўтган» - мавжуд ArAging/ApAging service'дан overdue
     жами;
   - «Жами сотув» (мижозда) / «Жами харид» (таъминотчида) - GL
     contact-кесим агрегати (LedgerDashboard нақши, тарихий жами);
   - «Охирги тўлов» - контактнинг охирги payment санаси.
3. **Кўчирма бўлими**: мавжуд StatementService (opening + running
   balance + closing) жадвали, давр филтри (default: охирги 12 ой),
   ҳужжат рақамлари ЛИНК (DEC-063 услуби). Барча суммалар home
   валютада (сарлавҳада ёзилади - statement қолипи).

Рўйхат row-click манзиллари янги кўриш саҳифасига алмашади
(ui-navigation-display.md T7 банди ниҳоят тўғри ҳолга келади);
глобал қидирув контакт натижаси ҳам шу саҳифага олиб боради
(ҳозир edit'га борарди - мослаштирилади).

## Дизайн қарорлари

- **Композиция CONTROLLER қатламида** (contact.web'да янги
  ContactCardController ёки мавжуд ContactController кенгайиши):
  ҳар модулдан фақат PUBLIC service (StatementService, aging,
  LedgerDashboardService, ContactService) - қоида 6 сақланади,
  ledger ҳеч кимга боғланмайди (у фақат маълумот беради).
- EMPLOYEE тури БУ САҲИФАГА КИРМАЙДИ (payroll кесими бошқа - ходим
  картаси 2-босқич; рўйхатда ходим row-click аввалгидек edit'га).
- Скриншотдаги ЧАП master-detail панель (рўйхат ёнма-ён) MVP'да
  ҚИЛИНМАЙДИ - катта layout иши; оддий саҳифа навигацияси кифоя.
- Excel export ҚИЛИНМАЙДИ (print бор) - 2-босқич.
- Changeset КЕРАК ЭМАС (фақат ўқиш - янги маълумот сақланмайди).
- Мобил 375px: стат-карталар 2×2 grid, кўчирма .table-wrap.

## Тестлар (мажбурий)

1. Controller/service: стат-карталар қийматлари (қолдиқ = statement
   closing; overdue aging билан мос; аванс белгиси салбий қолдиқда).
2. Кўчирма жадвали render + давр филтри (web тест).
3. Row-click манзили ва қидирув контакт линки янги саҳифага (smoke).
4. VIEWER_AUDITOR роли саҳифани кўра олади (read-only маълумот).
5. ScreenSmokeTest: /customers/{id}, /vendors/{id}.

## Экранлар

- `/customers/{id}`, `/vendors/{id}` - юқоридаги таркиб.
- Рўйхатлар (customers/vendors) row-click → кўриш; «Таҳрир» тугмаси
  формага.

## 2-босқич (ҳозир ЭМАС)

- Чап master-detail панель (рўйхат + саҳифа ёнма-ён, скриншотдагидек).
- Ҳужжатлар таби (тур бўйича филтрланган рўйхатлар), Excel export.
- Ходим картаси (payroll кесими: ойлик тарихи, тўловлар).
- Кўчирмани email қилиш (DEC-040 print/email оиласи билан).
