# Бизнес қоидалар каталоги

**Ягона манба (source of truth): `shared.exception.BusinessRule` enum** -
ҳар қоида у ерда HTTP status + код + default хабар билан туради, код
enum номидан автоматик келади (BR_LED_001 -> "BR-LED-001"). Бу файл -
инсон ўқийдиган кўзгу; иккаласи бирга янгиланади.

Ҳар бир қоида бузилиши `BusinessRuleException` (ёки унинг ворислари)
билан отилади - exception фақат enum қабул қилади, string код
компиляцияда ўтмайди. Хато экранида код хабар олдида кўрсатилади -
қўллаб-қувватлашга мурожаатда шу код айтилади.

Иерархия: `shared.exception.BusinessRuleException` (базавий) ->
`NotFoundException` (404, NOT_FOUND) ва `ledger.service.PostingException`.
HTTP status қоидада: оддий бузилиш 400, дубликат/идемпотентлик 409,
топилмади 404.

Янги қоида қўшишда: аввал enum'га ва шу файлга, кейин код
(posting-rules.md паттерни).
