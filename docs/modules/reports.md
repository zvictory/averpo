# Reports - Balance Sheet / P&L / Inventory Valuation / Dashboard (9-босқич) - SPEC

## Мақсад
Молиявий ҳисоботлар пакети: Balance Sheet, Profit & Loss, Inventory
Valuation ҳамда QBO home услубидаги Dashboard. Ҳаммаси мавжуд GL
маълумотидан ўқийди - янги ҳужжат тури, янги posting йўқ. Ҳисоблар
Trial Balance намунасида: JdbcClient SQL агрегат, POSTED+REVERSED
(сторно жуфти неттоси нолга тушади), барча суммалар home валютада.
Ўқиладиган проводкалар шакли: docs/posting-rules.md (эталон);
ledger ядроси: docs/modules/ledger.md. (Ҳаволалар: Ulugbek-030.)

## Қатъий қарорлар (2026-07-06 тасдиқланган)

- **Dashboard карталар + содда SVG график**: server-side JTE'да чизилади,

- **Кутубхонасиз давр preset'лари**: Бу ой / Бу чорак / Бу йил / Ўтган
  ой / Ўтган чорак / Ўтган йил - select, танланганда from/to тўлади.

## Молия йили созламаси (changeset 024)
QBO «First month of fiscal year» аналоги: `company_settings.
fiscal_year_start_month` (integer 1..12, default 1 - январь).
Balance Sheet'даги Тақсимланмаган фойда / Соф фойда бўлинишини
белгилайди. Хоҳлаган пайт ўзгартирса бўлади - фақат ҳисобот
кўринишига таъсир қилади, сақланган маълумотга тегмайди (QBO ҳам
қулфламайди). Валидация: BR-SET-004 (1..12 оралиғи).

Молия йили бошланиши (asOf санасига нисбатан):
`fyStart = LocalDate.of(asOf.month >= m ? asOf.year : asOf.year - 1, m, 1)`.

## Balance Sheet (`/reports/balance-sheet`)
«Санага» ҳисобот (asOf, default бугун). Тузилма QBO'ники:

- **АКТИВЛАР**
  - Жорий активлар: Банк счётлари (BANK) → Дебиторлик (AR) → Бошқа
    жорий активлар (OTHER_CURRENT_ASSET), ҳар тур ўз гуруҳ сарлавҳаси
    ва жамиси билан → Жами жорий активлар
  - Асосий воситалар (FIXED_ASSET)
  - Бошқа активлар (OTHER_ASSET)
  - **Жами активлар**
- **МАЖБУРИЯТ ВА КАПИТАЛ**
  - Жорий мажбуриятлар: Кредиторлик (AP) → Кредит карта → Бошқа жорий
    → Жами жорий мажбуриятлар
  - Узоқ муддатли мажбуриятлар (LONG_TERM_LIABILITY)
  - **Жами мажбуриятлар**
  - Капитал: EQUITY счётлари + иккита ҳисобланган сатр:
    - **Тақсимланмаган фойда**: RETAINED_EARNINGS detail type'даги
      счёт қолдиғи + олдинги молия йиллари соф фойдаси (QBO услуби:
      yopish проводкасисиз виртуал «roll»). RE счёти бўлмаса виртуал
      сатр кўрсатилади.
    - **Соф фойда**: жорий молия йили (fyStart..asOf) Даромад - Харажат.
  - **Жами капитал**
  - **Жами мажбурият ва капитал**

Ишора: актив сатрлари Dt-Cr, мажбурият/капитал Cr-Dt (мусбат - нормал
қолдиқ). Ноль қолдиқли счёт сатрлари яширилади (QBO default). Пастда
текширув: Жами актив == Жами мажбурият + капитал (фарқ бўлса огоҳлантириш
banner - GL бузилганини билдиради, бўлмаслиги керак).

Соф фойда (ҳар икки bucket): P&L турдаги (INCOME, OTHER_INCOME, COGS,
EXPENSE, OTHER_EXPENSE) счётлар бўйича Σ(creditBase - debitBase) -
даромад Cr-мусбат, харажат Dt айирилади, битта йиғинда чиқади.

## Profit & Loss (`/reports/profit-loss`)
Давр [from, to] (default: шу йил боши - бугун). Тузилма QBO'ники:

| Бўлим | Тур | Ишора |
|---|---|---|
| Даромад | INCOME | Cr-Dt |
| Сотилган товар таннархи | COST_OF_GOODS_SOLD | Dt-Cr |
| **Ялпи фойда** | Даромад - COGS | |
| Харажатлар | EXPENSE | Dt-Cr |
| **Операцион фойда** | Ялпи - Харажатлар | |
| Бошқа даромад | OTHER_INCOME | Cr-Dt |
| Бошқа харажат | OTHER_EXPENSE | Dt-Cr |
| **Бошқа фойда (нетто)** | | |

Ноль сатрлар яширилади. Ҳар сатрдан «Счёт амаллари»га drill-down
(даври билан).

## Inventory Valuation (`/reports/inventory-valuation`) - 3-туртки
QBO Inventory Valuation Summary + бизнинг multi-warehouse кенгайтма:
санага (asOf), товар кесимида: Миқдор / Қиймат (home) / Ўртача таннарх
(қиймат/миқдор). Омбор фильтри (танланса фақат ўша омбор) ва товар
ичида омбор кесими (кенгайтирилувчи сатрлар ёки иккинчи даража).
Ҳисоб stock_movement агрегатидан (санага қайта тиклаш - StockBalance
фақат жорий ҳолат). Landed cost movement ёзмасдан қиймат қўшади -
унинг улушлари `LandedValueContribution` ПОРТИ орқали киради
(интерфейс inventory'да, имплементация purchase'да - қоида №6 бўйича
йўналиш тўғри). Сторно ойнаси аниқ бўлиши учун landed_cost_allocation'га
reversal_date қўшилди (changeset 025): улуш allocation_date дан
reversal_date гача «кучда». Жами қиймат GL'даги INVENTORY тизим счёти
қолдиғи билан солиштирилади - фарқ бўлса огоҳлантириш (мос келиши
шарт, чунки ҳар омбор ҳаракати GL билан бир транзакцияда ёзилади;
фарқ фақат счётга қўлда JE/OB ёзилганда чиқади). GL солиштируви
фақат омбор фильтрисиз кўрсатилади (GL'да омбор кесими йўқ).

## Dashboard (`/` бош саҳифа) - 4-туртки + Arbitr-036 бойитиш (2026-07-08)
QBO home услуби, карталар:
- **P&L карта**: жорий ой даромад/харажат/соф фойда + охирги 6 ой
  бар-график (SVG, даромад/харажат жуфт устунлар).
- **Cash flow карта** (Arbitr-036): охирги 6 ой пул оқими - BANK
  счётлар GL ҳаракатидан кирим (Dt base) / чиқим (Cr base) жуфт
  устунлар + жорий ой нетто (monthlyCashFlow, monthlyPl нақши).
- **Банк қолдиқлари**: ҳар BANK счёти ўз валютасида + home'да, жамиси.
- **Инвойслар (AR)**: очиқ жами / муддати ўтган / **охирги 30 кунда
  тўланган** (paidTotal - reverse чиқарилган), AR aging'га ҳавола.
- **Харидлар (AP)**: очиқ жами / муддати ўтган жами, AP aging'га ҳавола.
- **Харажатлар тақсимоти**: жорий ой топ-5 харажат счёти, горизонтал
  барлар + бошқалар йиғиндиси.
- **Тез амаллар** (Arbitr-036): Invoice/Чиқим/Кирим/Ўтказма/Bill/JE
  яратиш линклари - EDIT рухсатисиз ролларга (VIEWER_AUDITOR)
  кўринмайди.
- **Inventory карта** (Arbitr-036, multi-warehouse кенгайтмамиз):
  жами захира қиймати (InventoryValuationService.companyValue) +
  омборлар сони, /inventory/balances'га ҳавола.
Ҳар картадан drill-down линк (P&L→ҳисобот, банк сатри→счёт амаллари,
cash flow→/bank-transactions ва ҳ.к.). Давр танлаш ва янги chart
кутубхонаси АТАЙЛАБ йўқ (кўлам қарори, 2026-07-07).
Бош саҳифа `/` dashboard'га айланади (ҳозирги redirect алмашади).

## Туртки режаси (ҳар бири алоҳида тасдиқланади)
1. Spec (шу ҳужжат) + молия йили созламаси (changeset 024, BR-SET-004,
   settings формаси) + BalanceSheetService + ProfitAndLossService +
   unit тестлар.
2. Balance Sheet ва P&L экранлари: давр preset'лари, drill-down,
   «Барча суммалар <home> да», 375px; sidebar ҲИСОБОТ янгиланиши.
3. InventoryValuationService + экран + GL солиштирув + тестлар.
4. Dashboard (карталар + SVG) + бош саҳифа алмашуви + roadmap ✅.

## Тестлар (мажбурий рўйхат)
- BS: актив/мажбурият ишоралари (банк Dt-мусбат, AP Cr-мусбат);
  жорий йил фойдаси Соф фойда сатрида; ўтган йилги фойда Тақсимланмаган
  фойдада (RE счёти билан қўшилган); молия йили ойи ўзгарса bucket
  тўғри кўчади; Жами актив == Жами мажбурият + капитал; REVERSED
  нетто ноль.
- P&L: бўлим жойлашуви (INCOME/COGS/EXPENSE/OTHER_*), Ялпи/Операцион/
  Соф фойда арифметикаси; давр фильтри (ташқаридаги entry кирмайди);
  ноль сатр яширилади.
- Молия йили созламаси: BR-SET-004 (0, 13 рад), сақланади.
- Inventory valuation (3-туртки): AVCO/FIFO қийматлари санага тўғри
  тикланади, омбор фильтри, GL солиштирув тенг.
