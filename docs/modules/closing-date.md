# Closing date lock - SPEC

## Мақсад
QBO услубидаги давр ёпилиши: PERIOD_CLOSE имкониятли роль
(SUPER_ADMIN ёки CHIEF_ACCOUNTANT) ёпилиш санасини белгилайди, шу
санага тенг ёки ундан олдинги санага янги GL ҳаракати ёзилмайди.
Эски лойиҳадаги тўлиқ fiscal_period жадвали СОДДАЛАШТИРИЛГАН
(docs/old-erp-ideas.md §2): битта сана CompanySettings'да туради,
керак бўлса кейин тўлиқ давр жадвалига кенгайтирилади.

## Entity'лар
Янги entity йўқ - `CompanySettings`'га битта майдон қўшилади:

| Майдон | Тип | Изоҳ |
|---|---|---|
| closing_date | date, nullable | Ёпилиш санаси; NULL - қулф йўқ (default) |

QBO'даги ихтиёрий closing date пароли ҲОЗИРЧА олинмади (соддалаштириш).

## Service API
- `CompanySettingsService.closingDate` - жорий ёпилиш санаси (NULL мумкин).
- `CompanySettingsService.update(...)` - closingDate параметри қўшилди;
 NULL юборилса қулф олинади. Сана ҳар қандай бўлиши мумкин, орқага/
 олдинга суриш PERIOD_CLOSE эгалари ихтиёрида (QBO ҳам чекламайди).

## Қоида (BR-LED-020)
Ёпилиш санаси белгиланган бўлса, `entry_date <= closing_date` бўлган
ҲАР ҚАНДАЙ янги GL ҳаракати тақиқ. Текширув PostingService'да - GL'га
ёзишнинг ягона йўли (темир қоида №2), учта нуқтада:

1. `createDraft` - ёпиқ даврга draft ҳам яратилмайди (эрта, аниқ хато).
2. `post` - draft очиқ даврда яратилиб, кейин ёпилиш санаси сурилган
 бўлиши мумкин - post олдидан ҚАЙТА текширилади.
3. `reverse` - сторно санаси (reversalDate) очиқ даврда бўлиши шарт.
 Ёпиқ даврдаги ҳужжатнинг ЎЗИНИ reverse қилиш МУМКИН: REVERSED
 ҳужжат балансда қолади (TrialBalance status IN POSTED/REVERSED),
 ёпиқ давр қолдиқлари ўзгармайди - сторно ўз санасида акс этади
 (QBO'даги «тузатиш ёпилишдан кейинги санада» услуби).

Draft'ни ўчириш чекланмайди - draft GL қолдиқларига таъсир қилмайди.

## Экранлар
/settings/closing-date (PERIOD_CLOSE имконияти - SUPER_ADMIN ва
CHIEF_ACCOUNTANT): «Ёпилиш санаси» date input, бўш қолдирилса
қулф йўқ. Изоҳ: шу кунгача (шу кун билан бирга) проводка тақиқ.

## Тестлар (мажбурий рўйхат)
- Ёпиқ даврга createDraft/createAndPost тақиқ (BR-LED-020).
- Draft очиқ пайтда яратилиб, кейин сана белгиланса - post тақиқ.
- Сторно санаси ёпиқ даврда - reverse тақиқ.
- Ёпиқ даврдаги ҳужжат очиқ санали сторно билан reverse бўлади.
- Ёпилиш санасидан кейинги сана - ҳаммаси бемалол ўтади.
- closing_date NULL - қулф умуман ишламайди.
