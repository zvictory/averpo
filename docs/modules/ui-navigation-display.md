# UI навигация ва кўрсатиш қоидалари - SPEC

Тасдиқланган:. Уч қисм: row-click навигация (T), валюта ва
бирлик кўрсатиш (U), кўрсатиш аниқлиги (V). Эталон - QuickBooks Online.

## Умумий тамойиллар

- **Ҳужжат рўйхати** - қатор босилса ҳужжатнинг ўзи очилади
  (DRAFT - таҳрирга, POSTED - кўришга).
- **Каталог рўйхати** - қатор босилса таҳрир формаси.
- **Форма қолиплари (фойдаланувчи қарори,, DEC-024)**:
  ТРАНЗАКЦИЯ формалари (invoice, bill, тўловлар, JE, ўтказма,
  кирим/чиқим, landed cost) - FULL экран (layout.form: қора бар + ,
  sticky footer, QBO transaction takeover). КАТАЛОГ формалари
  (счёт/item/contact) - ўнгдан slide-out drawer (shared/drawer.jte
  қолипи: HTMX partial юклаш, controller HX-Request'да *FormFields
  partial render қилади, оддий сўровда тўлиқ саҳифа - JS'сиз fallback
  ШАРТ; муваффақиятда HX-Redirect + flash). Янги каталог формаси
  ёзилса drawer қолипи олинади; янги транзакция формаси - FULL.
- **Счёт/ҳисобот қатори** - ўша кесим амаллари рўйхатига drill-down.
- Қатор ичидаги мавжуд тугма/link'лар ишлашда қолади - row-click улар
  устида ишламайди.
- **«+ Янги» панели (DEC-038, QBO Create нақши)** - sidebar тепасидаги
  «+ Янги» тугмаси кўп устунли МЕГА-ПАНЕЛ очади: устунлар навигация
  гуруҳлари (Сотув / Харид / Банк / Бухгалтерия / Омбор / Иш ҳақи), ҳар
  устунда ўша гуруҳнинг «янги ҳужжат» ҳаволалари - бир қарашда ҳамма тур
  кўринади (тор бир устунли dropdown эмас). Десктоп: оқ фонли кенг панел
  (~4 устун) + дим backdrop; мобил 375px: тўлиқ кенгликдаги bottom-sheet,
  гуруҳлар кетма-кет, скролланади. Очиш/ёпиш Alpine; backdrop босилса ёки
  Esc ёпади, x-cloak (drawer қолипи). Фақат ёза оладиганларга (canEdit;
  VIEWER_AUDITOR кўрмайди). Янги ҳужжат тури қўшилса шу панелга ҳам банд қўшилади.
- Пул ҳеч қачон «яланғоч» кўрсатилмайди; миқдор доим бирлиги билан.
- Яхлитлаш ФАҚАТ кўрсатишда - сақланадиган/ҳисобланадиган қийматлар
  тўлиқ аниқликда қолади (Money scale 4, курс/таннарх scale 12).

## C қисм - Кўрсатиш аниқлиги (V)

| Қиймат тури | Кўрсатиш | Мисол |
|---|---|---|
| Пул суммаси | минг ажратгич + қатъий 2 хона (HALF_UP) | `12 600.50` |

Қоида (фойдаланувчи тасдиқлаган): каср ажратгичи ҳамма

## D қисм - Киритиш: формат ва мини-калькулятор (W)

Фойдаланувчи талаби. Пул/миқдор/курс киритиладиган ҲАР
БИР майдонда: (1) ёзиш пайтида формат - минг ажратгич NBSP, вергул
нуқтага айланади (money-input.js механизми, DEC-011 дан бор);
(2) мини-калькулятор - Excel услубида, АТАЙЛАБ минимал (QBO amount
майдонлари ҳам шундай inline ҳисобни қўллайди - эталонга мос).

Калькулятор қоидалари:

- Триггер: майдон қиймати «=» билан бошланса. «=» сиз - оддий сон.
- Амаллар ФАҚАТ: `+ - * /`. Устуворлик оддий: аввал `* /`, кейин
  `+ -`. Қавс ЙЎҚ, функция ЙЎҚ, даража ЙЎҚ - мураккаблаштирилмайди.
- Ҳисоблаш вақти: blur ёки Enter - натижа майдонга форматланган
  ҳолда ёзилади, «=» йўқолади. «=» режимида Enter форма submit
  қилМАЙди (аввал ҳисоб).
- Ифода ичида форматланган сонлар ҳам қабул: «=12 600*2» (NBSP/
  пробел), вергул каср ҳам («=5,5*3»).
- Хато ифода ёки нолга бўлиш: қиймат ҳисобланмай ўз ҳолича қолади -
  submit'да одатдаги server валидацияси ушлайди. Ҳеч қандай alert йўқ.
- `eval` ИШЛАТИЛМАЙДИ - кичик қўлда токенлаш/ҳисоблаш (хавфсизлик).
- Жой: money-input.js кенгаяди - битта файл, event delegation
  сақланади (HTMX/Alpine динамик сатрлари ҳам қамралади).

## E қисм - Курс кўрсатиш йўналиши (X)

Фойдаланувчи талаби: курс ҳамиша «кучли» валюта
бирлигида кўрсатилади - «1 USD = 12 600 UZS»; ҳеч қачон
«1 UZS = 0.00008333 USD» эмас (йўналишдан қатъи назар: USD→UZS
ҳам, UZS→USD ҳам бир хил кўринади).

- Устуворлик рўйхати (default, кодда константа): USD > EUR > RUB >
  CNY. Жуфтликда рўйхатдагиси бор бўлса - у БИРЛИК (базис) томон;
  иккиси ҳам бўлса - рўйхатда олдинроғи (USD/EUR → «1 USD = ... EUR»).
  Ҳеч бири йўқ бўлса - қиймати ≥1 чиқадиган йўналиш (умумий фолбэк).
- **ОНГЛИ ФАРҚ QBO'дан (фойдаланувчи тасдиғи)**: QBO
  ҳамиша «1 <чет валюта> = X <home>» кўрсатади, кучли-кучсизга
  қарамай (жонли QBO'да home=USD билан «1 UZS = 0.000083 USD»
  кузатилди - фойдаланувчи скриншоти). Биз кучли-валюта-базис
  қоидасини АТАЙЛАБ сақлаймиз - «1 UZS = 0.00008 USD» кўриниши
  ўқилмас. Home=UZS ҳолатида (жонли база) иккала ёндашув бир хил
  кўринади - фарқ фақат home кучли валюта бўлганда билинади.
- Созламада танлаш - 2-БОСҚИЧ (ҳозир default кифоя; фойдаланувчи
  розилиги). CompanySettings/changeset ҳозир ЙЎҚ.
- САҚЛАШ ЎЗГАРМАЙДИ: Money (amount+baseAmount+exchangeRate) ва курс
  каталоги конвенцияси жойида қолади - бу ФАҚАТ кўрсатиш/ёрлиқ
  қоидаси. Тескари йўналишда 1/x фақат экран учун ҳисобланади
  (Fmt.rate, C қисм курс қоидаси: >= 1 → 2 хона, < 1 → макс 8 хона) -
  сақланадиган қийматга тегилмайди.
- Ёрлиқ қолипи (i18n): «1 USD = 12 600 UZS».

| X0 | shared'да кичик helper: orient(codeA, codeB, rate) → (базис, котировка, қиймат); устуворлик константаси + ≥1 фолбэк; unit тест | |
| X1 | Кўрсатиш жойлари свипи helper орқали: transferView/transfers, JE view курслари, invoice/bill/payment view, statement, currencyRates каталог ёрлиғи - grep билан тўлиқ рўйхат | |

## Пагинация стандарти (фойдаланувчи қарори, DEC-105)

QBO услубида, барча рўйхат экранларида бир хил (shared/
pagination.jte + марказий size helper):
- Ҳажм танлагичи: 25 (default) / 50 / 100 / 200; танланганда
  1-саҳифага қайтади.
- Танлов COOKIE'да эслаб қолинади - ҳар рўйхат ўз калити билан
  (ps_<рўйхат>); устуворлик: URL параметри > cookie > default.
  Бузуқ/бегона қиймат - жим default (whitelist).
- Кўрсаткич: «Жами X та, Y-Z кўрсатиляпти» + Биринчи/Олдинги/
  Кейинги/Охирги тугмалар (оддий GET линклар, JS'сиз).
- Филтрлар саҳифа ва ҳажм линкларида сақланади (filterQuery
  суффикси нақши).
- Ҳар ЯНГИ рўйхат экрани шу стандарт билан ТУҒИЛАДИ (доимий
  қоида, NAVBAT'да ҳам бор).
